# Budsbox

A Minecraft-styled music player with a Spotify-style layout: shared library, playlists, lyrics, album covers, shuffle/repeat, and "Jam" listen-together.

- Single page: `index.html` (no build step). Backend: Supabase (auth, database, storage, realtime).
- Hosted on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
- Database setup SQL is in the comment at the top of the `<script>` in `index.html`.
